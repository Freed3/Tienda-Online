# 🛒 Tienda Online

Proyecto de **tienda online** desarrollado con tecnologías web modernas. Incluye una **parte pública para clientes**, un **panel de administración** y un **backend** para la gestión de datos.

Este repositorio está pensado como proyecto educativo y base para el desarrollo de un sistema de comercio electrónico.

---

## 📌 Descripción general

La **Tienda Online** permite visualizar productos desde una interfaz web y cuenta con una estructura separada para:

* **Frontend de la tienda** (usuarios/clientes)
* **Panel de administración**
* **Backend (servidor / lógica de negocio)**

El proyecto está organizado para facilitar el aprendizaje y la ampliación de funcionalidades.

---

## 🧱 Estructura del proyecto

```
Tienda-Online/
│
├── admin/        # Panel administrativo
├── tienda/       # Frontend de la tienda (clientes)
├── back/         # Backend / servidor
├── node_modules/ # Dependencias (generado automáticamente)
├── package.json  # Configuración del proyecto y scripts
├── package-lock.json
```

## 🚀 Instalación y ejecución

### 1️⃣ Clonar el repositorio

```bash
git clone https://github.com/Freed3/Tienda-Online.git
cd Tienda-Online
```

### 2️⃣ Instalar dependencias

```bash
npm install
```

### 3️⃣ Ejecutar el proyecto

Dependiendo de los scripts configurados:

```bash
npm start
```

ó

```bash
npm run dev
```

Revisa el archivo **package.json** para ver los scripts disponibles.
